# Changelog

All notable changes to the OpenNotes project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-26

### Added
- **Reading-First Mobile Experience**: Lazy-loaded rich text editor on demand with lightweight reading mode (**36.6 kB** bundle).
- **Fullscreen Mobile Editor**: Dedicated dialog editor interface for single-column mobile formatting.
- **5-Tab Material 3 Bottom Navigation**: Native mobile navigation with `Home`, `Discover`, `Create`, `Bookmarks`, and `Profile` tabs.
- **Master Study Notes Prompt Generator**: University-grade preset generating semantic HTML study notes with formulas, comparison tables, exam focus (2/5/10 marks), and 10 interview Q&A pairs.
- **Theme-Adaptive Logo Branding**: SVG branding supporting Light Mode and Dark Mode.
- **Markdown-to-HTML Migration Utility**: Automatic batch converter for legacy Firestore Markdown notes.
- **DOMPurify HTML Security Sandbox**: Strict client-side HTML sanitization preventing XSS attacks.
- **Material Design 3 Dashboard**: Refined Overview statistics cards with sparklines and 1440px centered grid container.
